## 面板結構重點

```
┌─────────────────────────┐
│ 飛鏢猴          [i] [X] │  ← header：塔名、info、關閉
│ ★0                      │
├─────────────────────────┤
│  [塔圖示 - 藍色背景]    │  ← 塔圖（約佔上半 40%）
│                         │
│ ◄  第一個  ►            │  ← 路線名稱 + 左右切換箭頭
├─────────────────────────┤
│ ████ 未升級  [尖銳 $120]│  ← 路線1：4格進度點 + 升級按鈕
├─────────────────────────┤
│ ████ 未升級  [快速 $85] │  ← 路線2
├─────────────────────────┤
│ ████ 未升級  [長程 $75] │  ← 路線3
├─────────────────────────┤
│ 💰$119        [賣出]    │  ← 賣出區（深色底）
└─────────────────────────┘
```

## 關鍵設計細節
- **三條升級路線同時顯示**（不是一次一條）
- 升級按鈕是**五邊形**綠色形狀，帶升級圖示 + 名稱 + 價格
- 左側「未升級/已升X級」文字 + 4個方塊進度指示
- 路線名稱（第一個/第二個/第三個）在塔圖下方，用 ◄► 可能是切換塔的目標優先順序或額外資訊，非切換升級路線顯示
- 賣出區：左邊金幣圖示 + 返還值，右邊紅色賣出按鈕
